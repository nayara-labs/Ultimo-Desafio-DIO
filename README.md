# 📊 Projeto de Data Analytics com Power BI

## 📌 Descrição

Este projeto foi desenvolvido para o desafio de Data Analytics da DIO, com foco na construção de visualizações analíticas utilizando Power BI.

O objetivo foi transformar os dados em informações estratégicas através de análises estatísticas, explorando tendências, distribuições, agrupamentos e comportamento dos indicadores de vendas.

Além dos aspectos visuais, o desafio também contemplou a aplicação de conceitos de experiência do usuário (UX), organização de páginas e navegação interativa.

---

## 🎯 Objetivos do Projeto

- Desenvolver análises orientadas a dados.
- Construir visualizações estatísticas.
- Explorar padrões e tendências de vendas.
- Melhorar a experiência do usuário através da navegação entre páginas.
- Aplicar conceitos de Data Analytics no Power BI.

---

## 🏗️ Estrutura do Relatório

O projeto foi organizado nas seguintes páginas:

### 🏠 Home Page

Página inicial contendo os principais indicadores do relatório:

- Total de Vendas
- Unidades Vendidas
- Descontos
- COGS
- Análise temporal das vendas
- Vendas por Segmento
- Vendas por Produto
- Vendas por País

Além disso, foram adicionados botões de navegação para facilitar a experiência do usuário.

---

### 📋 Página de Detalhes

Página criada para aprofundamento das análises, permitindo maior exploração dos dados através dos filtros e segmentações disponíveis.

---

### 🏆 Página TOP N & Outliers

Nesta página foram desenvolvidas análises estatísticas e comparativas utilizando:

#### TOP 3 Produtos

Visualização dos produtos com melhor desempenho em vendas.

#### Principais Países

Análise dos países com maior participação em vendas.

#### Gráfico de Dispersão

Utilizado para identificar padrões e possíveis outliers através da relação entre:

- Vendas
- Lucro
- Unidades Vendidas

#### Análise Temporal

Comparação do desempenho dos produtos ao longo dos meses.

---

### 📈 Página Data Analytics

Página voltada para análises estatísticas dos dados.

#### Correlação

Gráfico de dispersão entre:

- Unidades Vendidas
- Vendas

Permitindo identificar tendências e possíveis correlações entre variáveis.

#### Top 5 Meses

Identificação dos meses com melhor desempenho.

#### Distribuição dos Dados

Utilização de histogramas para análise da frequência de vendas por faixa de valores.

#### TOP 3 Países

Análise dos países com maior volume de vendas.

---

### 🧩 Página Categorias & Cluster

Desenvolvida para análise de agrupamentos dos dados.

#### Compartimentação

Utilização de segmentação para identificar padrões entre categorias.

#### Clusterização

Agrupamento de registros com características semelhantes para facilitar a identificação de comportamentos de vendas.

---

## 📊 Medidas Criadas
